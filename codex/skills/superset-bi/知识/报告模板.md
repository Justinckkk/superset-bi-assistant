# 直接回答与分析报告模板

## 简短查数

【来源标签】游戏全名及编号；日期 YYYY-MM-DD 至 YYYY-MM-DD（起含止不含，北京时间选窗）。
结论：实际查询数字与单位（数字多时用表格）。口径：主体、去重、分子分母、内部号、天龄/成熟度。
限制：尚未到期、缺字段、范围不支持、截断或来源不可用均直说。可选看板链接放最后。
无数可取时说“未取到数据”，不编数字；追问或拒绝时不需要伪造数字或日期。

## 分析报告

结论 → 证据表（每项带来源、游戏、具体日期、口径）→ 多种解释 → 数据限制 → 下一步验证。
新增/cohort报告：导入 → 留存 → 成长/玩法 → 付费 → 同窗同天龄对照。
付费专项：固定窗口分层 → 商品收入/购买账号 → 首充/复购边界 → 内部号差异。
活动复盘：机制与可比窗口 → 资格/参与 → 现金收入与资源毛/净消耗分别列 → 验证动作。
技术诊断：初始化/下载/登录链 → 设备/系统/网络切片 → 同版本同进度对照 → 待验证反馈。
经济专项：期初—获得—消耗—期末先平衡，未知原因单列。
预测专项：实测、假设、预测分栏，说明成本、归因、成熟窗和情景，不给无依据的回本日。

事实、解释、建议分层写；不用历史案例数字、人名、账号、经验阈值或内部资料路径。
