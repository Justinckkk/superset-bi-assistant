# 指标与统计主体（按需读取）

只保留通用方法；实际可用指标、单位、阈值以 MCP 数据集说明为准。

| 指标 | 解释与易错点 |
|---|---|
| DAU | 单日去重活跃账号；跨天不能相加当区间独立账号 |
| 新增 | 本项目核准为创建当天登录的账号，不等于首次创角或安装 |
| 付费金额/人数 | 金额单位读元数据，人数按账号去重；不能由事件条数替代 |
| 付费率 | 付费账号÷活跃账号；展示百分数或小数须读指标说明 |
| ARPU / ARPPU | 收入÷活跃账号 / 收入÷付费账号；不是商品配置价格 |
| 留存 | 同一创建群体在第 N 日活跃比例，创建当日为第1日；不是连续登录 |
| 衰减 | 第 N 日留存÷第 N−1 日留存，不是1减留存 |
| LTV | 指定群体截至第 N 日累计收入÷新增；不是利润、也不是项目流水 |
| LTV比值 | 两个天龄累计LTV之比，必须说明分子分母；未指定默认比值/持续模式 |
| 商品销售 | 现金真实充值；购买账号、充值事件条数、商品件数、去重订单分别表述 |
| 付费分层 | 账号在指定窗口累计充值后分档，不按单笔或VIP等级；换窗重算 |
| 首充 | 历史第一笔真实付费归充值日，不是窗口内第一笔，也不是新增首日付费 |
| 流失 | 试行连续未登录口径；未到期NULL不是零；停留流失÷到达与整体率分开 |

账号、角色、设备是不同主体；不能混用去重键。事件金额、游戏资源数量、库存快照不能混加。归因、币种、自然日、付费窗口、成熟度不同的数据不可直接对比。相关性不等于因果；设备故障、难度或活动效果需对照验证。
